# monte-carlo-simulation
DESCRIPTION

Simulation project for developing a News Vendor Problem application to a bakery production

CONTENTS

This package contains the following files:

- README

- Group208_Project_Report.Rmd 

- shiny folder that contains the following files:
	- app.R     
	- helpers.R
	 
INSTRUCTIONS

- Group208_Project_Report.Rmd is the source code for the report and documentation on the code for the app.

- To run the app,

	- you will need an R installation

	- make sure you have both files app.Rand helpers.R in the shiny folder

	- run app.R
